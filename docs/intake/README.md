# Fichas de información de proyectos

Estas fichas sirven para reunir hechos antes de escribir los casos del portfolio.

## Cómo completarlas

1. Escribir debajo de cada línea `Respuesta:`.
2. No hace falta usar lenguaje comercial ni redactar bonito.
3. Se puede responder con frases sueltas, listas o links.
4. Si un dato no está disponible, usar una de estas marcas:
   - `PENDIENTE`: existe, pero falta buscarlo o confirmarlo.
   - `NO APLICA`: no corresponde al proyecto.
   - `NO DISPONIBLE`: no existe o no se conservó.
   - `PRIVADO`: existe, pero no debe publicarse.
5. No adivinar tecnologías, fechas ni resultados.
6. No pegar contraseñas, claves, accesos ni datos personales de clientes.

## Qué ocurre después

Alejandro aporta la información en bruto. Luego se utiliza para:

- separar hechos publicables de datos privados;
- definir el relato del caso;
- redactar ES y EN;
- identificar screenshots y evidencia;
- actualizar los pendientes;
- decidir si el caso será completo o compacto.

No es necesario reunir todo en una sola sesión. Primero se completa la sección “mínimo necesario” de cada proyecto.
