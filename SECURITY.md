# Security policy

This repository is a public, sanitized portfolio snapshot. It must not contain production credentials, private lead data, private resource locators or operational project identifiers.

Only `.env.example` may be versioned. Production configuration belongs in Sites, and credentials must be stored there as secrets. Private portfolio operations, working assets, career pipelines and generated output remain outside this repository's tracked surface.

Please report a suspected vulnerability privately by emailing [alegfink@gmail.com](mailto:alegfink@gmail.com). Do not include secrets or personal data in a public issue.

Only the latest version on `main` is maintained. Dependency updates are monitored through Dependabot and validated with the repository's full quality workflow.
